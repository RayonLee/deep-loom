# 开工检索

1. 复制[空白查询卡](schema/query.yaml)，填写任务目标、主题、明确包含和排除的材料。
2. 从部署者提供的本地目录查找候选条目。核对条目元数据、原文版本和定位。
3. 从已确认的对象出发，沿强链接 `follows`、`enables`、`informs` 查找一到两步。把与当前目标有关且允许使用的材料放入检索包。
4. 用 `objects` 和 `object_edges` 记录对象预览，也可将同样结构放在任务目录的 `retrieve/loom-preview.json`。零命中时记录查找范围与原因，保留空列表。
5. 收工时记录实际使用和未使用的材料。新对象和关联先标为 `proposed`，按[归档规则](archive.md)确认后写回。

检索包每项记录条目 ID、关系和入选理由。对象预览每项记录对象 ID、状态、任务用途和材料引用。条目、对象、边的字段见[模板](schema/README.md)。
