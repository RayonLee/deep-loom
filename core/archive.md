# 归档规则

先确认任务的交付版本和允许留存的材料。模块提交专业产物、原始依据、用到的条目，以及拟议对象和边。调度角色确认后，登记已接纳的元数据和关系。

- 条目保留稳定 ID、版本日期、来源和原文位置。对象保留稳定 ID 与相应材料引用。
- 关系明确主体、客体、类型和证据。确认时保留有效期和来源。原关系失效时记录终止时间。
- 实际用于任务的关系可在确认后从弱链接升为强链接，记录使用位置。只保留为线索的关系维持弱链接。
- 归档产物按工作区授权存放。时限项目验收后可迁至已办结目录，保留必要的过程元数据。

[模板字段](schema/README.md)提供归档所需的空白结构。[模块图](module-graph.md)说明跨模块读写边界。
