# 任务分派

先确认用户目标、可用材料和交付目录。选择能直接交付当前任务的主模块。跨模块需求写入交接记录，由调度角色确认范围后分派。

| 任务信号 | 主模块 |
|---|---|
| 指定全文的结构、方法和证据解读 | [论文精读](../modules/paper-reading/SKILL.md) |
| 学术问题和研究设计预验证 | [学术构思与预验证](../modules/research-ideation/SKILL.md) |
| 文献筛选、证据矩阵与综述 | [论文检索与综述](../modules/paper-writing/SKILL.md) |
| 教材章节与教学内容结构 | [教材章节编写](../modules/textbook/SKILL.md) |
| 指南适配和申请书论证 | [中文课题申报](../modules/grant-writing/SKILL.md) |
| 教学案例与教学笔记 | [教学案例写作](../modules/case-writing/SKILL.md) |
| 引用、事实和来源核对 | [引用与文本审查](../modules/citation-audit/SKILL.md) |

每轮按[检索规程](retrieve.md)记录来源、适用范围与缺口。专业产物写入当前项目的 `work/`。任务结束后提交采用的材料、待确认对象和关联，由调度角色按[归档规则](archive.md)处理。
