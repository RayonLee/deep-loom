# 教材章节编写

确认适用读者、课程目标、章节前后关系和格式要求。先从获准材料形成大纲，并为各节列出要解释的概念与拟用依据。

1. 按读者所需的先备知识安排章节顺序。
2. 起草解释、过渡、小结和练习要求，把可核验的事实对应到来源。
3. 汇总并核对引用，对章节内引文和参考资料做双向检查。
4. 按用户提供的格式交付当前版本，注明未解决的资料或样式问题。
