# 论文精读

开工确认全文版本、阅读目标和关注部分。把论文和获准资料登记到当前项目的检索包。对论文事实标注页码、图表或章节。

| 阅读视角 | 记录重点 |
|---|---|
| 科研分析 | 问题、设计、证据和可用启发 |
| 原文对照 | 段落内容、公式定位及上下文 |
| 批判性阅读 | 假设、替代解释和外推边界 |
| 文献定位 | 论文与前序工作的关系 |
| 证据链 | 主张、出处与支持强度 |
| 快速泛读 | 问题、发现与适用范围 |
| 方法精读 | 测量、设计和推断限制 |
| 论文叙事 | 论文的核心问题及论证展开 |

按用户指定范围生成笔记。单独标记论文原文、解释和待核问题。没有全文时记录缺失范围。交付前逐项核查引述、页码和版本。笔记保存在当前项目，待确认的条目和关系走核心归档流程。
