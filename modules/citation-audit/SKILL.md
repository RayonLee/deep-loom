# 引用与文本审查

确认原稿版本、要核查的范围、证据深度和交付格式。保留文字位置与核验过程。

1. 从原稿逐条提取引文与可核查主张，核对文内引用和参考文献表。
2. 核实所引来源的身份、版本、可访问范围与原文定位。
3. 将原稿措辞与来源逐条对照，记录支持程度、范围和证据缺口。
4. 按影响程度列出问题、证据定位和建议。未访问或未解决的内容保留待核状态。
