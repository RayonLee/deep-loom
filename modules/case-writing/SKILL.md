# 教学案例写作

确认教学目标、目标读者、正文与教学笔记各自的范围。明确可用材料、事实口径和哪些细节需要用户确认。

1. 梳理背景、关键人物或角色、时间线与决策情境，保留证据定位。
2. 正文交待决策发生前可获得的信息和候选方案，保留可讨论的冲突。
3. 教学笔记给出学习目标、讨论问题、课堂安排及相应分析依据。
4. 核对材料中的事实、角色同意、引用、两份文档之间的一致性和交付格式。
