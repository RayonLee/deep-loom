Seven academic workflows

  • Research ideation

    Narrow a research question and check competing explanations, data access, and inference conditions.

  • Literature search and review

    Log searches and screening, verify bibliographic details, and build an evidence matrix and review.

  • Close reading

    Take notes on a paper’s structure, methods, evidence, and limitations.

  • Textbook chapters

    Organize learning objectives, chapter structure, explanations, and citations.

  • Chinese grant applications

    Use the call guidelines to choose a direction, build the argument, and plan the work.

  • Teaching cases

    Write the case and teaching note, with traceable support for factual claims.

  • Citation and text audit

    Check citations, factual claims, and sources, then document revisions.

Layout and runtime

core/
Workflow guides, module graph, field templates, and Python tools
modules/
Seven academic workflows, the additional capability, and their module declarations
templates/
Blank configuration for the deployment

Four core Python tools extract text, calculate project time, append usage records, and report usage. Use Python 3.10 or later. DOCX extraction uses the standard library. PDF and legacy DOC extraction require a local converter.

Operators handle retrieval, archiving, and handoffs. Close reading, chapters, grant applications, cases, and citation audit are manual workflow guides. The original generators and dashboard, automated retrieval and archiving, and project workbook sync are outside this distribution.

Day-to-day work takes place in the local primary workspace. The separate public copy is for releases and design reference. The export area is for release preparation and records. Maintenance
